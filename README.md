# Zrobleno

Темний україномовний Flutter-застосунок для справ, витрат, харчування, ліків і дружньої щоденної підтримки.

## v0.2

- точна локальна база продуктів: бренд, варіант, штрихкод, вага, калорії та БЖВ на 100 г, джерело і ручна перевірка;
- повторне додавання їжі з власної бази без нового пошуку даних;
- системні ранкові та вечірні нагадування про таблетки з налаштуванням часу та тестовим сповіщенням;
- синичка-помічниця з короткими підказками, зернятками, ростом, гніздечком і садочком;
- гумористична Клякса після пропущеного дня без штрафів і втрати прогресу;
- завдання, витрати, фото чека з ручним підтвердженням та харчування зберігаються локально.

Розпізнавання чеків, захищений AI-сервіс, Google Drive/Sheets, голосове планування та автоматичні бази продуктів заплановані наступними вертикальними етапами. Інтерфейс не видає ручне підтвердження чека за готовий OCR.

## Запуск

```bash
flutter pub get
flutter run
```

Для Android потрібні Flutter stable, Android SDK та JDK 17. Мінімальна версія Android — API 23.

CI APK підписується публічним `zrobleno-test.keystore`, щоб тестові версії можна було оновлювати поверх попередніх. Цей ключ призначений лише для тестування; реліз Google Play використовуватиме окремий приватний ключ.

## APK

Workflow **Android APK** запускає аналіз, тести та release-збірку. У GitHub відкрийте **Actions → Android APK → останній успішний запуск → Artifacts** і завантажте `zrobleno-android-apk`.
