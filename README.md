# Zrobleno

Україномовний Flutter-застосунок для справ, витрат, харчування, ліків і щоденної підтримки у стилі затишної casual-гри.

## v2.0 — перший ігровий vertical slice

- **Справжня сцена:** Старий сад працює в ігровому циклі Flame. Синичка має кадрову анімацію, стартує точно на гілці й рухається до місця дотику.
- **Цілісна графіка:** локація, квіти, трава й гриби — один мальований растровий світ. Старі SVG-подібні квіти та декоративний `CustomPaint` прибрані.
- **Повний день квестів:** 12 базових щоденних квестів плюс до 8 власних справ, дві сюжетні групи, смуга прогресу, досвід, зерна й окремий скарб дня.
- **Подія Клякси:** виконання ритуалу ліків запускає пробіжку персонажа в меню та відкриває мінібоса у світі.
- **Видимий розвиток:** чотири мальовані стани годівнички, святкові частинки та карта майбутніх локацій.
- **Збереження прогресу:** щоденні квести, одноразові нагороди, рівні світу й події зберігаються локально без можливості нескінченно забирати одну нагороду.

Це перший завершений зріз майбутньої RPG: одна локація, один супротивник і повний цикл «квест → нагорода → розвиток світу». Наступні акти можуть додаватися без перебудови побутових модулів.

## v1.3 — мальований квестовий інтерфейс

- **Кольорове ігрове меню:** п'ять зрозумілих розділів із власними кольорами та великими активними станами.
- **Щоденні пригоди:** ліки й справи показуються як квести на теплій паперовій картці. Виконаний прийом ліків замінює порожню клітинку на таблетку й нараховує зернятка.
- **Новий головний екран:** сцена синички, коротка порада помічника, рівень, зернятка, активні справи й швидкий перехід у чат або ігровий світ.
- **Каракуляста Клякса:** окремий 8-кадровий растровий атлас у навмисно простому намальованому стилі.
- **Видимі нагороди:** годівничка має чотири графічні рівні, а після покращення синичка підстрибує й перекидається, з'являються конфеті та піксельний феєрверк.
- **Ігрова типографіка:** локальний моноширинний шрифт із підтримкою української, без завантаження шрифтів з мережі.

## v1.2 — AI та жива піксельна гра

- **AI-сканер чеків:** читає магазин, дату, валюту, загальну суму та товарні позиції. Дані зберігаються тільки після перевірки користувачем.
- **AI-сканер етикеток:** дістає назву, бренд, штрихкод, вагу, ккал і БЖВ на 100 г. Невидимі значення не вигадуються, а позначаються як відсутні.
- **Синичка-помічниця:** чат бачить сьогоднішні записи, калорійну ціль, активні справи й приймання ліків. Запропоновану їжу або витрату треба окремо підтвердити.
- **Google Sheets:** підтверджені витрати, позиції чеків, продукти та їжа синхронізуються в окремі вкладки. Повторна синхронізація оновлює запис за ID, а не створює дубль.
- **Pixel-art світ:** растровий 16-бітний фон, кадрові PNG-атласи синички й Клякси, рух, мерехтіння, сад, гніздо та коротка сценка Клякси. SVG у грі не використовується.
- **Offline-first:** локальні справи, витрати, харчування, продукти, налаштування та історія чату зберігаються на телефоні. Без інтернету ручні функції продовжують працювати.

## Як влаштований AI

Android-застосунок не містить ключ OpenAI. Фото або повідомлення надсилаються в особистий Google Apps Script, де ключ лежить у Script Properties. Скрипт викликає OpenAI Responses API з image input і Structured Outputs, а потім повертає застосунку структурований JSON.

Код шлюзу й покрокове налаштування: [`backend/apps-script`](backend/apps-script/README.md).

> AI може помилитися на нечіткому фото. Сума, калорійність і БЖВ завжди показуються для ручної перевірки перед збереженням.

## Локальний запуск

```bash
flutter pub get
flutter run
```

Потрібні Flutter stable, Android SDK і JDK 17. Мінімальна версія Android — API 23.

## APK

Workflow **Android APK** запускає `flutter analyze`, тести та release-збірку. У GitHub відкрийте **Actions → Android APK → останній успішний запуск → Artifacts** і завантажте `zrobleno-android-apk`.

CI APK підписується публічним тестовим ключем, щоб нову тестову версію можна було встановити поверх попередньої. Для Google Play потрібен окремий приватний ключ.
