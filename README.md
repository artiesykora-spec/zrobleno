# Zrobleno

Темний україномовний Flutter-застосунок для щоденних справ, який повністю працює без інтернету.

## MVP

- завдання й нотатки з категоріями, пріоритетами, дедлайнами та виконанням;
- екран «Сьогодні» зі зведенням справ, витрат, калорій та ліків;
- фото чека з камери або галереї з ручним підтвердженням суми й категорії;
- історія витрат з додаванням, редагуванням і видаленням;
- щоденник харчування: калорії, білки, жири та вуглеводи;
- ранкова й вечірня відмітка ліків, яка оновлюється щодня;
- локальне JSON-сховище у `SharedPreferences` без серверів і API-ключів.

## Запуск

```bash
flutter pub get
flutter run
```

Для Android потрібні Flutter stable, Android SDK та JDK 17. Мінімальна версія Android — API 23.

## APK

Workflow **Android APK** запускає аналіз, тести та release-збірку. У GitHub відкрийте **Actions → Android APK → останній успішний запуск → Artifacts** і завантажте `zrobleno-android-apk`.
