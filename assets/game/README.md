# Game art

Растрові 16-бітні PNG-ресурси, створені для Zrobleno:

- `bird-atlas.png` — 8 кадрів синички, сітка 4 × 2;
- `wolf-atlas.png` — 6 кадрів Клякси, сітка 3 × 2;
- `world-background.png` — фоновий сад.

Рендер виконується без згладжування (`FilterQuality.none`) через кадровий атлас у `lib/widgets/pixel_bird.dart`.
