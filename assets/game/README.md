# Game art

Растрові 16-бітні PNG-ресурси, створені для Zrobleno:

- `bird-atlas.png` — 8 кадрів синички, сітка 4 × 2;
- `wolf-atlas.png` — 6 кадрів Клякси, сітка 3 × 2;
- `klaksa-atlas-v2.png` — 8 кадрів каракулястої Клякси, сітка 4 × 2;
- `feeder-atlas-v2.png` — 4 рівні дерев'яної годівнички, сітка 4 × 1;
- `world-background.png` — фоновий сад.

Рендер виконується без згладжування (`FilterQuality.none`) через кадровий атлас у `lib/widgets/pixel_bird.dart`.

Нові v2-атласи створені як растрові pixel-art ресурси за референсами інтерфейсу: Клякса — навмисно груба чорна каракуля з довгою пащею й паличками-лапами; годівничка — одна й та сама тепла дерев'яна конструкція у чотирьох послідовних станах. Після генерації фон перетворено на справжню прозорість для накладання у Flutter.
